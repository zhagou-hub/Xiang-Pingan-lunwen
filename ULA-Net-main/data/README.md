# Dataset placement guide

This project expects hyperspectral unmixing datasets as MATLAB `.mat` files.

## Directory layout

```text
data/
├── raw/
│   ├── samson/           # put Samson .mat here
│   └── jasper_ridge/     # put Jasper Ridge .mat here
└── synthetic/            # auto-generated by scripts/generate_synthetic.py
```

## Samson

- Typical size: `95 x 95` pixels, `156` bands, `3` endmembers (soil / tree / water).
- Files expected in `data/raw/samson/`:
  - `Samson.mat` (cube `V`, plus `nRow`/`nCol`/`nBand`)
  - `Samson_GT.mat` (abundance `A`, endmember `M`)
- Sources:
  - Original: http://lesun.weebly.com/hyperspectral-data-set.html (Zhu Feiyun Dataset_GT)
  - Mirror used in this project: https://github.com/gaetanosettembre/data_unmixing

Accepted variable names (case-insensitive):

| Role | Candidate keys |
|------|----------------|
| Cube | `Y`, `X`, `V`, `data`, `cube`, `hsi` (2-D `L×N` or 3-D) |
| Size | `nRow`, `nCol` (required when cube is `L×N`) |
| Abundance GT | `A`, `A_true`, `abundance`, `abundances` |
| Endmember GT | `M`, `M_true`, `endmembers`, `E` |

Cube layout can be `(H,W,L)`, `(L,H,W)`, or `(L,N)` with `nRow`/`nCol`; the loader normalizes to `(H,W,L)`.

## Jasper Ridge

- Typical size: `100 x 100` pixels, `198` bands (already band-cleaned) or `224` raw bands, `4` endmembers.
- Files expected in `data/raw/jasper_ridge/`:
  - `jasperRidge2_R198.mat` (cube `Y`, optional `maxValue`)
  - `Jasper_GT.mat` (abundance `A`, endmember `M`)
- Bands removed automatically when raw cube has ≥220 bands (1-based, as in the paper):
  `1–3`, `108–112`, `154–166`, `220–224`.
- Same key-name conventions as Samson.

## Synthetic

No download needed:

```bash
python scripts/generate_synthetic.py --config configs/synthetic.yaml
```

This writes `data/synthetic/synthetic_scene.npz` with keys `Y`, `A`, `M`, `S`.

## Quick check

```bash
# should fail with a clear message if .mat is missing
python scripts/train.py --config configs/samson.yaml --epochs 1
```
